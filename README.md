# 小鱼联机 RPG（2~4 人）

## 有什么
- 4 个职业：战士、法师、游侠、牧师（进房间按座位分配，1P 战士、2P 法师、3P 游侠、4P 牧师）
- 每个职业 5 个技能，等级 2 / 4 / 6 / 8 / 10 解锁
- 法师和牧师都有「复活」，能救倒下的队友
- 击杀给金币和经验，升级加攻加血并回满
- 商店：买药（无上限）、强化武器（+3 攻）、强化护甲（+12 血），价格随次数上涨
- 打满 12 只怪后刷最终 BOSS「灰烬王·终焉」，打败算通关
- 人不满也能开，2 人、3 人都行

## 目录
- server.js：全部战斗逻辑、职业、技能、怪物、商店、BOSS（**改数值改这里**）
- public/index.html：界面（**改样式改这里**）
- package.json：只依赖 ws

## 跑起来
```
npm install
npm start
```
打开 http://localhost:8080 ，房间号填一样的就能一队。

## 部署
Render：New → Web Service → 连仓库 → Build `npm install` → Start `npm start`。

## 技能表
- 战士：重斩 / 盾击（晕） / 自愈 / 怒吼（加攻） / 斩杀
- 法师：火球 / 冰霜（晕） / 吸血 / 复活 / 陨石
- 游侠：连射 / 陷阱（晕） / 急救 / 毒箭 / 替身（闪避）
- 牧师：治疗 / 群疗 / 圣光 / 复活 / 祈祷
